# Unified Engineering Engine: Superpowers + AgentMemory

This configuration coordinates **Superpowers** (disciplined workflow skills, collaborative brainstorming, structured planning, systematic debugging, and TDD) and **AgentMemory** (persistent cross-session memory, lesson recall, and knowledge graph tracking) into a single unified engineering engine powered by `/ship`.

---

## The Master Protocol: Active on Every Request

Whenever any task, bug, feature, or refactor is requested (including `/ship`, `/build`, or standard prompts):

### Step 1: Context & Lesson Recall (AgentMemory Preflight)
Before designing or touching any code:
1. **Automated Mission Preflight**:
   ```bash
   python3 ~/.gemini/config/skills/ship/scripts/ship_preflight.py "<task_keywords>"
   ```
   *(Project is auto-detected from the active git repository or directory. Do NOT hardcode `--project` unless explicitly overriding.)*
2. **Review Output**:
   - Inspect active domain invariants and past bug root causes.
   - Note the **🚨 MANDATORY SUPERPOWERS DIRECTIVE** generated by the preflight engine.
3. **Fallback Manual Checks (if script unavailable)**:
   - Query lessons: `curl -s -m 2 http://localhost:3111/agentmemory/lessons`
   - Check graph stats: `curl -s -m 2 http://localhost:3111/agentmemory/graph/stats`
   - Memory recall: Call `memory_smart_search(query=<task_keywords>)` or `memory_recall(query=<file_path_or_concept>)`.

---

### Step 2: Skill Invocation Rule (`using-superpowers`)
<EXTREMELY-IMPORTANT>
You MUST invoke the relevant Superpowers skill BEFORE taking any implementation action, reading project source code, running build commands, or making ad-hoc edits.
Announce: "Using [skill] to [purpose]" and follow the skill's workflow strictly.
</EXTREMELY-IMPORTANT>

#### For Bugs, Regressions, and Test Failures:
- **Invoke `systematic-debugging` FIRST**:
  1. Announce: `"Using systematic-debugging to investigate root cause."`
  2. Isolate the exact failing behavior without guessing.
  3. Formulate and verify a root-cause hypothesis before modifying any code.
  4. Write a minimal failing test reproducer (`test-driven-development`).
  5. Apply minimal fix to pass.

#### For Creative Work, Features, UI Behavior, or Design Decisions:
- **Invoke `brainstorming` FIRST**:
  1. Announce: `"Using brainstorming to explore intent and design."`
  2. Adopt the requested persona (e.g. user-first, focusing on real workflow and UX, not tech jargon).
  3. Frame the problem clearly, surface edge cases, and propose 2-3 concrete approaches with trade-offs.
  4. <HARD-GATE>
     **STOP AND WAIT FOR USER APPROVAL.**
     Do NOT write code, edit files, or jump to implementation until your human partner explicitly approves the design direction.
     </HARD-GATE>

#### For Planning Multi-Step Implementation:
- **Invoke `writing-plans`**:
  1. Break down approved work into clean, bite-sized tasks.
  2. Maintain a clear task checklist (`task_list.md`).

#### For Code Execution & Implementation:
- **Invoke `test-driven-development`**:
  1. Write the minimal runnable check or assertion first before implementing logic.
  2. Verify tests fail for the right reason, then implement minimal code to pass.

---

### Step 3: Structured Persistence & Knowledge Graph (AgentMemory Postflight)
Drive the full engine through its automated postflight persistence upon completing tasks (project is auto-detected):

1. **Automated Postflight Persistence**:
   ```bash
   python3 ~/.gemini/config/skills/ship/scripts/ship_postflight.py \
     --summary "<task_summary>" \
     --details "<details>" \
     --files "<comma_separated_files>" \
     --lesson "<imperative_rule_and_consequence>" \
     --context "<trigger_situation>" \
     --tags "<tag1,tag2>"
   ```
2. **Fallback Manual API Calls (if script unavailable)**:
   - **Record Lesson** (Populates **LESSONS** tab):
     ```bash
     curl -s -X POST http://localhost:3111/agentmemory/lessons \
       -H "Content-Type: application/json" \
       -d '{"project": "<active_project>", "content": "<lesson>", "context": "<context>", "confidence": 0.95, "tags": ["tag1", "tag2"]}'
     ```
   - **Record Observation** (Populates **TIMELINE** tab):
     ```bash
     curl -s -X POST http://localhost:3111/agentmemory/observe \
       -H "Content-Type: application/json" \
       -d '{"project": "<active_project>", "hookType": "task_completed", "sessionId": "session_id", "cwd": "'"$PWD"'", "timestamp": "'$(date -u +"%Y-%m-%dT%H:%M:%SZ")'", "data": {"task_subject": "<summary>", "task_description": "<details>"}}'
     ```
   - **Trigger Graph Extraction** (Builds **GRAPH NODES & EDGES**):
     ```bash
     curl -s -X POST http://localhost:3111/agentmemory/graph/extract \
       -H "Content-Type: application/json" \
       -d '{"project": "<active_project>", "observations": [{"id": "<obs_id>"}]}'
     ```
